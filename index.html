Tags

As tags HTML servem para indicar ao navegador a como organizar e exibir os textos e informações, geralmente compostas por uma abertura ”<” e um fechamento “>”

Tags para estruturação da página

- Tags como header,main e footer servem para manter a estrutura da página organizada

- header: serve para manter o texto na parte superior da página

- main: tem o propósito de manter o texto como a parte principal do site, deixando o texto no meio da página

- footer: tem o propostio de manter textos na parte inferior do site

Exemplo de utilização

Tags para Formatação e Conteúdo: (img)

- (h1) a (h6): servem para formatar o texto do formato desejado

- (p): tem o objetivo de usar parágrafo

- (img): serve para mostrar uma imagem na tela

Exemplo de utilização

Tags para Textos

- (a): serve para adicionar links

- (strong): serve para deixar o texto em negrito

- (em): serve para deixar o texto em itálico

- (br): serve para pular linha
